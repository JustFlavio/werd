# Werd 0.1.0-alpha.1

The first public alpha of Werd, a free native development environment for Laravel and PHP. This release provides a **Windows x64 installer**. macOS and Linux are development targets and are not supported by this installer.

## Included

- Local `.test` sites over HTTPS, per-site PHP versions, project linking and folder parking.
- PHP, Composer and Node runtime management with project-aware CLI shims.
- Shared PostgreSQL, MySQL, MariaDB, MongoDB, Redis, Mailpit, RustFS and Meilisearch services, with persistent data and connection details.
- A desktop app and CLI using the same daemon; a versionable `werd.yml` describes project requirements.
- Managed per-site Vite: start/stop, optional autostart, logs, HTTPS assets and hot reload. A frontend failure leaves PHP running; stopping the site also stops its managed Vite process.
- Signed Tauri updates through a dedicated preview channel. Application installers and runtime binaries now have separate release histories.

## Before using the alpha

- Install the project dependencies before starting Vite. Werd runs the project's Vite directly using its configuration and selected Node version; custom npm `dev` scripts/hooks are not executed. The standard Laravel `public/hot` location is required.
- When Vite is stopped, run your project's frontend build to serve the last built assets at the site's URL.
- Local HTTPS requires trusting Werd's local CA. Runtime downloads and creating new projects require internet access.
- pgvector currently requires Visual Studio Build Tools on Windows. Verified prebuilt packages are planned.
- Queue/scheduler supervision, Reverb management, database backup/restore, a dump viewer, an integrated Laravel log/mail viewer and Xdebug setup are still roadmap items. This alpha does not provide full Herd feature parity.

See the [README and setup guide](https://github.com/JustFlavio/werd/blob/v0.1.0-alpha.1/README.md), [official roadmap](https://github.com/JustFlavio/werd#official-roadmap) and [release policy](https://github.com/JustFlavio/werd/blob/v0.1.0-alpha.1/docs/releases.md).

Validated before publication: frontend and Rust tests, version/release guards, build and lint checks, and GitHub CI on Windows and Linux. Installer artifacts and updater entries are checked by the release workflow. Tauri updater signatures are distinct from Windows Authenticode signing.
